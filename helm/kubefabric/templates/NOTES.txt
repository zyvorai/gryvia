Install the KubeFabric CLI:

  # Linux
  curl -L https://github.com/ssahani/kube-fabric/releases/latest/download/kubefabric-linux-amd64 -o kubefabric
  chmod +x kubefabric
  sudo mv kubefabric /usr/local/bin/

  # macOS
  curl -L https://github.com/ssahani/kube-fabric/releases/latest/download/kubefabric-darwin-amd64 -o kubefabric
  chmod +x kubefabric
  sudo mv kubefabric /usr/local/bin/

Usage:
  kubefabric cluster              # View cluster status
  kubefabric submit -f job.yaml   # Submit a job
  kubefabric list jobs            # List all jobs
  kubefabric quota                # View team quotas

1. Verify all operators are running:
   kubectl get pods -n {{ .Release.Namespace }}

2. Check operator logs:
   kubectl logs -n {{ .Release.Namespace }} -l app=kubefabric-gpu-operator

3. View GPU nodes:
   kubectl get fabricgpunodes

4. Create a team quota:
   kubectl apply -f https://raw.githubusercontent.com/ssahani/kube-fabric/main/examples/quota/team-ml-quota.yaml

5. Submit your first job:
   kubectl apply -f https://raw.githubusercontent.com/ssahani/kube-fabric/main/examples/jobs/pytorch-distributed.yaml

6. Monitor job status:
   kubectl get fabricaijobs
   kubectl describe fabricaijob <job-name>
